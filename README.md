# Auth Starter

Небольшая страница входа и регистрации для портфолио. Клиент и сервер работают на обычном Node.js — сторонние пакеты и база данных не нужны.

## Запуск

Нужен Node.js 20 или новее.

```powershell
Copy-Item .env.example .env
node server.js
```

Откройте http://localhost:3000. Регистрация, вход по почте и паролю и выход работают сразу. Данные сохраняются в `data/users.json` и исключены из Git.

## OAuth: Google и GitHub

Создайте OAuth-клиент у провайдера и укажите в `.env` его ID и секрет. Callback URL должен быть:

- Google: `http://localhost:3000/auth/google/callback`
- GitHub: `http://localhost:3000/auth/github/callback`

Для другого адреса задайте `APP_URL` и добавьте соответствующий callback URL в настройках OAuth-приложения. После изменения `.env` перезапустите сервер. Если секреты не заданы, кнопка провайдера покажет сообщение о настройке.

Для Google включите OAuth consent screen и базовый профиль/email. Для GitHub создайте OAuth App; приложению нужны `read:user` и `user:email`.

## Безопасность и границы проекта

- Пароли хешируются встроенным `scrypt` с индивидуальной случайной солью.
- Сессия подписана HMAC, хранится в HttpOnly/SameSite cookie и истекает через семь дней. На HTTPS cookie автоматически получает флаг `Secure`.
- OAuth использует одноразовый state для проверки callback.
- Перед публикацией задайте случайный `SESSION_SECRET` в `.env`.
- JSON-файл — компактное хранилище для демо и портфолио. Для публичного production-развёртывания подключите базу данных, ограничение частоты запросов, HTTPS и восстановление пароля.

Приложение намеренно не отправляет почту и не утверждает владение email для локальных аккаунтов.

## GitHub Pages

`index.html`, `styles.css` и `app.js` лежат в корне репозитория, поэтому GitHub Pages сможет показать сайт без сборки. Запушьте проект на GitHub, откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.

Pages публикует только статические файлы. На опубликованной странице будет доступен интерфейс, но регистрация, вход и OAuth требуют Node.js API и не работают на одном GitHub Pages. Для полного приложения разверните сервер отдельно и подключите постоянную базу данных. Не добавляйте `.env` или реальные OAuth-секреты в репозиторий.
