# Auth Starter

Минимальный проект регистрации и входа по почте и паролю на Node.js. Есть профиль и выход из аккаунта; почтовые коды и OAuth не используются.

## Запуск

Нужен Node.js 20 или новее.

```powershell
Copy-Item .env.example .env
node server.js
```

Открой http://localhost:3000. Пользователи сохраняются в `data/users.json`; каталог с данными исключён из Git.

## Безопасность

- Пароли хешируются через встроенный `scrypt` с индивидуальной случайной солью.
- Сессия подписана HMAC и хранится в HttpOnly cookie с SameSite=Lax. На HTTPS добавляется флаг Secure. Сессия истекает через семь дней.
- Перед публикацией задай случайный `SESSION_SECRET` в `.env`.
- JSON-файл подходит для демонстрационного проекта. Для production нужны постоянная база данных, HTTPS, резервные копии и дополнительные меры защиты.

## GitHub Pages

Корневые `index.html`, `styles.css` и `app.js` позволяют опубликовать статический интерфейс через GitHub Pages. Регистрация и вход требуют работающего Node.js сервера, поэтому на одном GitHub Pages API не работает. Разворачивай проект как Node Web Service.

Не добавляй `.env` или реальные секреты в репозиторий.
